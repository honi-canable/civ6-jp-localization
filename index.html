GitHub連携 — チームで1つのMODを管理

親MOD・Requirements・Actions・翻訳ファイルはすべて指定したGitHubリポジトリに保存されます。同じリポジトリを指すメンバーは「読み込む」でお互いの変更を取得し、「保存する」で反映できます。
アクセストークンはこのブラウザのメモリ上でのみ使用され、保存・送信されることはありません（プロジェクトファイルにも含まれません）。

Fine-grained PAT の場合は対象リポジトリに対する Contents と Pull requests の Read and write 権限が必要です。

親MODリスト

翻訳対象となる元MOD、および Criteria 判定に使う submod をここに登録します。name は Criteria 名の生成に使われるため半角英数字（と - _）のみ使用してください。

Requirements（要求条件）

Criteria ブロック内に挿入する XML 条件断片を手動で入力します（例: <GameCoreVersionMatches>...</GameCoreVersionMatches>）。Actions からこのリストを選択して Criteria に組み込みます。

適用ファイル

.xml / .sql の翻訳ファイルをアップロードします。各ファイルは「親MOD」ごとのフォルダに格納され（フォルダ名 = MODのID）、その下に任意のサブパスを指定できます。
